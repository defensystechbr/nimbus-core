## 2. O que é o Nimbus

Dois aplicativos, uma conta (par de chaves no chip do aparelho):
- **NimbusChat** — conversas, grupos, chamadas, mensagens que somem, envio direto e NimbusDrop.
- **NimbusOne** — espaço de trabalho cifrado com continuidade entre iPhone, Android e computador: cofre, Sala Blindada (só no app), aprovações, console corporativo. Em revisão; o foco desta entrega é o NimbusChat pessoal.

Princípio: **acesso zero**. O servidor nunca tem chave de conteúdo. Diante de ordem judicial, a empresa cumpre e entrega o que existe: registros de acesso selados e dados de licença — conteúdo, contatos e histórico não existem para entregar.
